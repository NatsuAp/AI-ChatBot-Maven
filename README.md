Trabajo de aprendizaje para clase.

Un chatbot especializado en preguntas del curso AP Computer Science, GUI realizado con Java Swing, que usa la api de Gemini, mas una base de datos local con un banco de preguntas de la materia, el cual usa embeddings y la similaridad de coseno para comparar las preguntas y hallar la pregunta del usuario de modo que se mejore la precision del modelo.
